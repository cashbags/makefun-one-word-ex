# One Word From Your Ex — `fixer-upper`

A [make.fun](https://make.fun/bounty/u-brave-eagle-12-one-word-from-your-ex-cfd97ba2) entry for
**One Word From Your Ex** (`u-brave-eagle-12-one-word-from-your-ex-cfd97ba2`).

The program writes exactly one word — the word the entrant's ex would
use to describe them — to `/output/entry.txt`. The word is
**`fixer-upper`**: a house that needs work, applied to a person. The ex
looked at you, saw a renovation project, and tried to fix you. It
stings because it is true, and it is funny because the entrant plainly
knows it.

See [DESIGN.md](DESIGN.md) for why this word won the tournament and
the flood-check behind it.
